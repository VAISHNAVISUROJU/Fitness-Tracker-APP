# 🏋️‍♀️ Personal Fitness Tracker App

Hey there! This is a **Machine Learning-powered web app** that helps you **predict calories burned** based on your personal info and habits. Built with 💻 **Python**, 🔮 **Scikit-learn**, and ☁️ **Streamlit**, this beauty is designed to make your fitness smarter and sexier.

## 🚀 Features

- 🔢 User input via interactive sliders (age, weight, etc.)
- 📈 Predicts **calories burned** using trained ML models
- 🧠 Uses **Linear Regression** and **Random Forest Regressor**
- 💡 Clean, simple interface with **Streamlit**
- ⚠️ Handles warnings like a pro – no annoying clutter

## 📊 Tech Stack

- Python
- Pandas, Numpy
- Matplotlib, Seaborn
- Scikit-learn
- Streamlit
